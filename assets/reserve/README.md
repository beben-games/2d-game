# Reserve packs

Not used by the game yet; kept for weapon tiers, melee, and caster work. The folder is `.gdignore`d,
so nothing here is imported or exported until it is moved out. Neither pack is in the public repo
(`.gitignore`); the files live in the owner's working copy.

- `shikashi_v2/`: Shikashi's Fantasy Icons Pack v2, 245 icons at 32 px, transparent sheet. License in
  `LICENSE.txt` (free for commercial use; many icons derive from game-icons.net, CC BY 3.0).
- `casper_mz/`: Casper Gaming's RPG Maker MZ icon set (`IconSet.png`, 512 x 5120). Terms in
  `additional-terms.txt`: Casper Gaming's terms of use, and the artist Fauster must be credited.
