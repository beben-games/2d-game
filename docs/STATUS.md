## How to run and verify

```bash
tools/run.sh                                                # play: WASD, mouse aim, click to shoot, Space/right click dash, 1 to 5 or click picks a card, Esc pauses on the Options tab (resume, restart, volumes, quit) and Tab on Boons (the build), a third tab shows Training (the profile's lines), either key closes; R restarts (a yield mid-run; nothing in the grounds)
tools/run.sh --seed=N                                       # replay a run, skipping the title: same waves, and the same card offers given the same picks and the same hurt state at each clear (the seed is on the gate screen and in the RUN_END line)
tools/test.sh                                               # all suites headless, prints a digest (-v for everything, full log in reports/test.log); exit 0 pass
tools/check_boot.sh                                         # boots main scene headless and runs the reload probe (Play, Restart, Play, a fall to the gate screen, the grounds, Quit to title), fails on any error
tools/smoke.sh <idle|move|combat|kill|round|fall|pick|roar|title|pause|boss|grounds>   # scripted run in a 1280x720 window, screenshot in reports/; a 30 s in-process watchdog, reported as `watchdog: scenario hung`; every scenario fails if it ran silent (SMOKE_AUDIO 0)
tools/build.sh                                              # tester zips for Windows x64 and Linux x64 into builds/ (needs the export templates)
tools/release.sh                                            # publishes them as the GitHub release v<version> (gh auth login; the commit pushed first)
tools/input_probe.sh 25                                     # logs raw key/mouse/focus events (stuck-key diagnosis)
tools/gen_icons.py                                          # regenerates data/icons.json from the (row, col) table inside it
source tools/godot.sh && perl -e 'alarm 120; exec @ARGV' "$GODOT_BIN" --headless --path . -s tools/icon_sheet.gd </dev/null   # renders every icon to reports/icons.png; gen_guns.gd runs the same way
```

Smoke scenarios: `idle` (the arena, nothing spawning), `move` (run right and dash), `combat` (the real series, the first wave under fire), `kill` (a placed chaser dies, `SMOKE_KILLS 1`, the counter reads 1), `round` (clear a one-chaser round, take card 1, wait the gap, `SMOKE_ROUND 1`), `fall` (hp 1 against a chaser; `reports/smoke_fall_verdict.png` at the thumb, `SMOKE_VERDICT up`, then the gate screen, `SMOKE_GATE Porta Triumphalis`; the end capture is the screen over the black, dark by design), `pick` (clear the round, capture the paused cards under "Pick a boon" as `reports/smoke_pick_menu.png`, take card 1, `SMOKE_UPGRADE <id>`). `round`, `fall`, `pick`, and `roar` run on `tools/smoke_series.tres`; `title` (the front door, `smoke_title_screen.png`, then Play), `pause` (Esc, `smoke_pause_menu.png` on the Options tab, Esc), `boss` (`tools/smoke_boss_series.tres`, shoots the boss until its first ring, `SMOKE_BOSS_HP n of 600` below max under a visible bar), `roar` (the `pick` flow at full favour, `reports/smoke_roar_menu.png` after the crowd's gold card drops into the fourth slot, `SMOKE_ROAR 4`, `SMOKE_CROWD_ROARS 2`), `grounds` (`flags.returned` forced on the smoke tool's scratch profile, Play into the grounds, a walk into the post, `SMOKE_GROUNDS post`, the end capture with the training panel up: the money, the four lines' names (Offer, Reroll, Mercy, Reach) beside their icons with the pips and the prices, the strip under the rows empty until a row is hovered, when it shows that line's text). The smoke tool and the reload probe use their own scratch profiles (`user://smoke_profile_<pid>.cfg`, `user://probe_profile_<pid>.cfg`, per process and removed at the end), never the player's save.

Testing aids: the title's seed field takes cheat codes from `scripts/cheats.gd`: `permawhat?` (immortal), `verso` (the thumb goes down), `dives` (the run starts with `RunState.RICH_COINS`, 1000); a cheated run takes a random seed and its gate screen, its record, and its `RUN_END` line say `cheats=<flags>`. Beside them, `tabula` (`Cheats.ACTIONS`, a title-time action, not a run flag): Play backs the save up to `<path>.bak`, replaces it with the defaults (`Profile.wipe`), and starts an uncheated first run.

## How the work was done

Subagent-driven development from the plans in `docs/plans/2026-09-02-arena-roguelike-m0-m1.md`, `docs/plans/2026-09-04-milestone-2.md`, `docs/plans/2026-09-08-milestone-3.md`, `docs/plans/2026-09-15-milestone-4.md`, and `docs/plans/2026-09-25-milestone-5.md`: one implementer per task, then a spec-compliance review, then a code-quality review, with fixes re-reviewed before the next task, and the plan re-synced with every deviation. Milestone 3 used the loop over fifteen tasks, Milestone 4 over ten, Milestone 5 over eighteen (the build's seven, then five from playtest 1 and six from playtest 2); their plans record every deviation found in review (the flash shader that ignored `modulate`, the load cycle through the enemy bolt, the refund rounds that accumulate, the stun that interrupts a telegraph, the audio release race at quit, the charge that only a wall ends, the verdict that cannot be skipped, the piles swept at a thumbs up, the save file backed up before the defaults load, and the rest). The plans are the record of what was built and why; the older plans' long code blocks were cut on 2026-09-24 and the M5 plan was written in the short form, so the committed files are the code reference. `CLAUDE.md` holds the conventions a session needs to keep working the same way.
