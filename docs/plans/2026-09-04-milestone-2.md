**Goal:** A run with a beginning and an end: four single-screen rooms of authored waves, a Shooter enemy with dodgeable bolts, a dash, a HUD, a heart reward per room, doors between rooms, and a death or win summary that waits for R.

**Architecture:** A `Room` scene owns everything that dies with a room (tiles, walls, doors, enemies, projectiles, spawner, wave runner); `Main` swaps rooms from a `FloorDef` and keeps the player, camera, HUD, and summary. New rules live in pure classes (`WaveProgress`, `ShooterBrain`, `DashRules`, `HeartRules`, `FloorRules`) unit-tested without a scene; scenes stay thin. Data is five small `Resource` classes under `data/`.

**Tech Stack:** Godot 4.7.2, GDScript, gdUnit4 v6.2.1, 0x72 Dungeon Tileset II.

**Design doc:** `docs/plans/2026-09-04-milestone-2-design.md`. Background: `docs/plans/2026-09-04-m2-prework-notes.md`, `CLAUDE.md`.

## A run: rooms in order. Clearing the last one wins.

@export var rooms: Array[RoomDef] = []


func validate() -> PackedStringArray:
	var errors := PackedStringArray()
	if rooms.is_empty():

			errors.append("room %d: %s" % [i, e])
	return errors
```

## `--seed=N` after `--` on the command line replays a run. Applied once per process, so R still
## gives a fresh seed afterwards.
func _apply_seed_argument() -> void:
	if _seed_arg_applied:
		return
	_seed_arg_applied = true
	for arg in OS.get_cmdline_user_args():
		if arg.begins_with("--seed="):
			RunState.start_run(int(arg.get_slice("=", 1)))
```
