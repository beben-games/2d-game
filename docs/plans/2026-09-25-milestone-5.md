# Milestone 5 Implementation Plan: rounds and the grounds

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A run is eight rounds in one arena with the crowd's favour, coins, a fall and a verdict, then a return to a grounds room where money buys training and the gate starts the next run; not one word of explanation anywhere.

**Architecture:** `SeriesDef` and `RoundDef` replace floors and rooms; one `Room` lives for the run and its wave runner takes the next round's table, so `Door` and the fade between rooms go. A `Favour` node under Main scores named acts through the pure `FavourRules`; coins are `EnemyDef` data flown to the HUD or thrown as `CoinPile`s; the `Profile` autoload owns a `Save` (money, training, flags, stats, a run log) and listens to the bus for the stats. The fall ends in a verdict scene and the `GateScreen`; the `Grounds` scene sits where the `Room` does, with three stations that open panels. Everything obeys the colosseum design's "show, don't tell".

**Tech Stack:** Godot 4.7.2, GDScript, gdUnit4 (`tools/test.sh`), the smoke tool (`tools/smoke.sh`), ffmpeg for nothing here (the sounds are in).

**Design:** `docs/plans/2026-09-25-milestone-5-design.md` (the intent and the numbers) under `docs/plans/2026-09-25-colosseum-design.md` (the direction). This plan is in the short form: files, behaviour, tests; the committed code is the reference once a task lands.
