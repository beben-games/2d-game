# The narrator's pool: one line at a time in the window at the verdict, over the drum roll and
# under the thumb, with no input. Every line is a PLACEHOLDER for the human writing. A timed
# event shows only its first shown line (a second line is never shown), so each event is one
# line. A verdict comes every run, so every event repeats; the lines of a moment rotate (the least
# recently played first). The verdict's lines are chosen before the run is banked: the profile's
# counts and the last_* names are the runs before this one, run_band is this run's.
