# The lint's word list (tools/story_lint.sh, the Story tab): a line or a choice holding one of these
# is a warning, since no line names a key or explains a system (the writing rule: text may
# reinforce, never explain). Not a pool: the story reads its pools by cast id. One entry a line;
# '#' starts a comment; any case. A {substitution} and the PLACEHOLDER marker are never read as prose.
#
# Two forms:
#   word            a plain entry, a word or a phrase: matched anywhere in a line, as whole words
#                   (a phrase's blank matches any run of blanks). Only terms that are never in the
#                   world's voice belong here; a word with an honest in-world use goes in as a
#                   phrase that pins its mechanic sense ("save the game", not "save").
#   key: name       a key's or an input's name: matched only where a line tells someone to use it
#                   ("press E", "hit the Space", "the E key", "the mouse button", "use the mouse
#                   to"; the lint's frames, StoryLint.KEY_FRAMES), so "Enter.", "a shift of guards",
#                   or "the key to the gate" pass. Every key the game binds to an action a line could
#                   name is here (tests/test_story_data.gd fails until a new binding's name is added).
#
# A false positive is silenced by editing this list (remove the entry, or narrow it to a phrase),
# never by a mark in the prose.
